# 🎮 Quiz Game

## 📖 Project Overview
Quiz Game is a simple, interactive web application that tests your knowledge with fun multiple-choice questions.  
It is built using **HTML**, **CSS**, and **JavaScript**. The game features a start screen, a quiz screen with questions, and a result screen showing your final score.

---

## ⚙️ Features
- ✅ Start quiz with a click  
- ✅ Multiple-choice questions  
- ✅ Track current question and total questions  
- ✅ Show score in real-time  
- ✅ Progress bar to visualize quiz progress  
- ✅ Display result message based on score  
- ✅ Restart quiz anytime  

---

## 🧰 Technologies Used
- **HTML** - for structure  
- **CSS** - for styling  
- **JavaScript** - for functionality
